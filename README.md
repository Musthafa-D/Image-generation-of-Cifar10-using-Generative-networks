# CIFAR-10 Image Generation Using Generative Networks (PyTorch)

## Project Overview

This project explores **image generation** on the CIFAR-10 dataset using generative models implemented in PyTorch.  
Generative models (e.g., GANs) learn to produce realistic images by modeling the distribution of real data.

CIFAR-10 is a standard benchmark dataset containing 60,000 32×32 RGB images across 10 classes.

This repository provides scripts for training generative models and visualizing the generated images.

---

## Dataset

- **CIFAR-10**
- 60,000 32×32 images (10 classes)
- Commonly used for both classification and generative tasks

In this project, both gans and conditional gans are implemented.

---

## What This Project Includes

- Data loading and preprocessing with PyTorch  
- Implementation of one or more generative models  
- Training pipeline
- Image generation and visualization  
- Comparison between real and generated samples
